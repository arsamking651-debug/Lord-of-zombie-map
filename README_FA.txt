پروژه اندرویدی Zombie Strike

این پروژه فایل HTML بازی را داخل یک WebView اندرویدی اجرا می‌کند.

ساخت APK بدون کامپیوتر (با گوشی):
1) وارد github.com شو و یک حساب رایگان بساز/وارد شو.
2) یک مخزن جدید (New repository) بساز و نامش را ZombieStrike بگذار.
3) فایل ZIP پروژه را از حالت فشرده خارج کن و محتویات پوشه ZombieStrike را در مخزن بارگذاری کن؛ پوشه .github هم باید بارگذاری شود.
4) از زبانه Actions، گردش‌کار Build Zombie Strike APK را انتخاب کن و روی Run workflow بزن.
5) پس از پایان موفق، وارد اجرای انجام‌شده شو، پایین صفحه بخش Artifacts را باز کن و ZombieStrike-debug-apk را دانلود کن.
6) فایل دانلودشده را از حالت ZIP خارج کن؛ فایل app-debug.apk داخل آن است.

نکته: این پروژه سورس آماده ساخت است، نه APK نهایی. ساخت APK در سرورهای GitHub انجام می‌شود. برای نصب، اندروید ممکن است اجازه نصب از منبع دانلود را بخواهد.
